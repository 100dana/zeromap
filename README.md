친환경 제로웨이스트 맵을 만드는 참여형 모바일 플랫폼

# 앱 개요

✅ **제로웨이스트 상점/시설 위치 기반 앱**

- **문제**: 다회용기 허용 카페, 무포장 상점, 리필스테이션, 비건식당 등의 위치를 알기 어려움
- **아이디어**: 친환경 소비를 할 수 있는 장소 정보를 사용자 참여형으로 공유/확장하는 지도 기반 앱
- **기술 스택**:
    - React Native + Firebase/Firestore
    - 사용자 제보 기반 크라우드소싱 구조
    - 카테고리 필터(무포장, 리필스테이션, 다회용기 사용 매장 등)
- **부가 기능**: 방문 후기, 별점, 뉴스
